bzCRM

Linked notes from Outlook and Teams about people, shared projects, and follow-ups.

bzCRM packages the existing private BZCOWCRM workflow for friends. The public package is not released yet. Installable bzCRM skills, a starter vault, and verified setup instructions are not available yet.

Read the guide and draft prompts

Start with one week

The planned setup uses GitHub Copilot CLI, Work IQ already connected, and your own Obsidian vault.

  1. Choose your Outlook and Teams sources, timezone, and notes folder.
  2. Read the last seven complete days. Save linked notes and stop.
  3. Check names, projects, follow-ups, and source links. Correct mistakes.
  4. Approve the trial, then choose how much older history to add.
  5. Request updates and ask questions about your saved notes.

Source access can be incomplete. The tool must show gaps and preserve your corrections. Your private notes stay outside this public repository.

Prompts and skills

The README lists draft prompts for the trial, corrections, older history, resume, updates, manual additions, conversation preparation, collaborators, follow-ups, and project and career histories.

Two core skills are proposed: bzcrm-ingest for reading sources and updating notes, and bzcrm-query for questions about saved notes. Histories start as query prompts. No public bzCRM skill is released yet.
