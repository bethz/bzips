bzCRM

Linked notes from Outlook and Teams about people, shared projects, and follow-ups.

bzCRM packages the existing private BZCOWCRM workflow for friends. Two draft skills are available. Live imports and each agent's access still need testing.

Start bzCRM

Run a quick trial using existing history

Work IQ is already set up. Use an agent that can read your selected sources and save your notes. The instructions work as skill files or text you provide; they do not add missing access.

Follow the setup guide, then:

  1. Copy this request: “Run a quick bzCRM trial. Read the past seven complete days of Outlook and Teams activity. Save the notes and show the results for my review.”
  2. Answer its questions about your mailbox, Teams activity, timezone, and notes folder.
  3. Check a few people and projects you know. Tell it what to correct.
  4. When you are happy with the trial, approve it and ask to add older history.
  5. Ask: “Can you ingest for bzCRM since the last time we ran?”

The trial checks source access and note saving with one week of existing history. It does not run for a week. Some information may be missing; bzCRM must tell you what it could not read. Your notes stay in your own folder, not in the public project.

Prompts and skills

The README lists draft prompts for the trial, corrections, older history, resume, updates, manual additions, conversation preparation, collaborators, follow-ups, and project and career histories.

A prompt is a request you type or paste. A skill is a set of instructions your assistant follows.

Import (bzcrm-ingest) reads selected sources and saves notes, a date log, and progress. Ask (bzcrm-query) answers questions from saved notes, including which dates were processed.

Import keeps its date log in your notes folder. Ask: “What dates have we ingested for bzCRM?” Incomplete ranges stay visible.
